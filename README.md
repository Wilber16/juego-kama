# Juego Kama 🔥

20 posturas para parejas (+18) en una web para el móvil. No necesita instalación y no envía datos a ningún servidor.

## Qué tiene

- 🎰 **Ruleta:** elige una postura al azar sin repetir hasta que salgan todas.
- 🔥 **Modo reto:** añade un desafío extra a cada postura (ojos vendados, muy lento, frente al espejo…).
- 🧍 **Diagramas de posición:** figuras tipo maniquí, dorado = él y rosa = ella.
- 📋 Cada postura incluye pasos para colocarse, un consejo y su nivel (fácil, medio o atrevido).
- ⏱️ **Temporizador** de 1, 2, 3 o 5 minutos, con vibración al terminar.
- ❤️ **Favoritas** y ✅ **"La probamos"**, guardadas en el móvil.
- Filtro por nivel.

## Publicarlo con GitHub Pages

**Settings → Pages → Deploy from a branch → `main` / `(root)`**. El enlace será:

`https://wilber16.github.io/Juego-Kama/`

## Archivos

- `index.html` — la app.
- `poses.js` — las 20 posturas: textos y diagramas.
